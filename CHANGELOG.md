# Change Log

All notable changes to the "Fast Run Tasks" extension will be documented in this file.

## [0.0.1] - 2025-10-19

### 🎉 Initial Release

#### Features
- ⚡ One-key execution for Python, Java, C, C++ files
- 🧹 Clean terminal output (no command clutter)
- 🎯 Smart Java package detection
- 🔄 Cross-shell support (PowerShell & CMD)
- ✅ Always compiles before running (fresh output guaranteed)
- ⌨️ Dual keyboard shortcuts: shift+`(shift+backtick)
- 🎨 Zero configuration required

#### Supported Languages
- Python (`.py`)
- Java (`.java`) with automatic package handling
- C (`.c`)
- C++ (`.cpp`)

#### Technical Highlights
- Uses VS Code Task API for reliable execution
- Detects `package` declarations in Java files automatically
- Handles both simple files and complex package structures
- Ensures compilation success before running code
